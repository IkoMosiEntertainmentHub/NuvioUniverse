# Nuvio Universe 1.0.0 — build 148

Based on official Nuvio Mobile **0.6.5-beta**, with the Universe additions below. Android **arm64-v8a only**.

## Added
- Universe replaces the detail-page Collections row for movies and series.
- Layout → Details → Universe: oldest to newest (default), newest to oldest, or most popular by IMDb vote count.
- Landscape cards by default, with an independent portrait-poster option.
- Universe preferences use the existing Nuvio profile settings sync when signed in.

## Fixed and improved
- Fixed missing public Nuvio account configuration in fork builds, which prevented normal account login.
- Fixed switching from guest mode after password or device-link sign-in.
- Limited Universe to sequels, prequels, and spin-offs in the same continuity; remakes and broad recommendations are excluded.
- Filtered shorts, episodes, brief videos, and known short runtimes from Universe results.
- Started fetching earlier, reused a bounded cache, and displayed available cards before landscape artwork finishes loading.
- Added a separate fork version and numeric version comparison for future in-app updates.

## Installation
- Install the `arm64-v8a.apk` asset below. This is a release build with a persistent signing key and a separate app identity from official Nuvio.
- This release installs separately from the earlier **Nuvio Universe Debug** APK. Keep that app until any guest-only settings have been saved or transferred.
- Future releases must use the same signing key and a matching or higher official build number to update this app in place.

## Validation and limits
- Android host tests cover Universe selection, sorting/settings, account-state transitions, and version comparisons. Build configuration validates the official public account endpoint without using account credentials.
- Actual password/device-link sign-in and phone behavior still need user verification. No personal account credentials were used during development.
- Universe relies on available IMDb connections; missing metadata can leave results incomplete. An uncached request still depends on network speed.

## Version convention
`<official version>-NuvioUniverse-<fork version> (build number)`

This release: **0.6.5-beta-NuvioUniverse-1.0.0 (148)**. Future releases will include notes listing additions, fixes, installation changes, and validation.
