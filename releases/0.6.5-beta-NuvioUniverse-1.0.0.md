# Nuvio Universe 1.0.0 — official build 148

Planned preview release based on official **Nuvio Mobile 0.6.5-beta**. Personal Android **armeabi-v7a and arm64-v8a** builds.

## Added

- Separate ARMv7 (armeabi-v7a) and ARM64 (arm64-v8a) APKs, signed with the same persistent release key.

- Separate Universe section directly below the preserved official Collections rail.
- Prequel/sequel, spin-off and remake/reboot connections using IMDb's follows, followed-by, spin-off, spin-off-from, remake-of and remade-as categories.
- Layout → Details → Universe controls for oldest first (default), newest first, or IMDb vote-count sorting.
- Landscape cards by default, with an independent portrait-poster option.
- Universe choices stored in the existing Nuvio profile-sync payload.

## Fixed and improved

- Fixed missing public Nuvio account configuration in personal builds and the guest-to-account transition.
- Restored official Collections with its original content and visibility rules.
- Filtered shorts, episodes, brief videos and known short runtimes.
- Started loading earlier, reused bounded cached results and displayed available cards before landscape artwork finishes.
- Updated the release feed for the renamed NuvioUniverse repository.
- Added independent personal version comparison while retaining the official build number.

## Installation

Use the matching signed ARMv7 or ARM64 APK when this release is published. CI unsigned artifacts require signing first. Production builds install separately from official Nuvio and earlier Nuvio Universe Debug builds; save any guest-only settings before removing a testing build.

Future production APKs must use the same private signing key. The version format is **0.6.5-beta-NuvioUniverse-1.0.0 (148)**: official base, personal version, official build number.

## Validation

The feature baseline passed **37 Android host tests**, **5 configuration checks**, and an ARM64 release build. The focused upstream proposal passed **27 Android host tests** and an original-identity Android debug build. These results precede the documentation and release-feed rename.

Earlier debug-build device screenshots demonstrate Universe in use. Current-revision combined Collections/Universe screenshots, current account-login verification and iOS verification remain pending. Provider coverage varies by title.

## Upstream contribution

The focused implementation is proposed at [NuvioMobile #2425](https://github.com/NuvioMedia/NuvioMobile/pull/2425). It preserves official branding/build configuration and makes Universe opt-in. Personal release configuration is kept in this repository.
